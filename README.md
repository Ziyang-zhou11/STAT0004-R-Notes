## 在 VS Code 中使用

1. 安装 R 和 VS Code 的 Jupyter 扩展。
2. 安装 Jupyter，并在 R 中安装 `IRkernel`：`install.packages("IRkernel")`。
3. 在 R 中运行 `IRkernel::installspec()` 注册内核（Jupyter 必须可从 PATH 访问）。
4. 打开 `.ipynb`，选择本机 R 内核，按 **Shift + Enter** 运行代码单元。

说明中的代码块用于阅读；各周“动手练习”代码单元可直接运行。涉及 `qanda` 的课程数据示例，需要自行取得并导入 `selective_affinities.csv`。仓库不包含课程原始 PDF 或调查数据。
